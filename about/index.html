Project overview

This subproject is organized around shared platform work, four Domain Programs, and a program of international knowledge circulation. It combines platform engineering, field-based validation, and recurring collaboration mechanisms in one research structure.

Why this project

The project responds to systems that require secure data, coordinated evaluation, and cross-domain learning.

Mobility, Manufacturing, Nursing, and Agriculture each involve complex operational settings in which data, models, and decisions need to be connected without losing domain context. ASPIRE addresses this by combining Core Platform capabilities with field-based Proofs of Concept (PoCs) and collaboration pathways that allow methods to move across domains.

What ASPIRE does

The project links Core Platform development, Domain Programs, and international collaboration.

Core Platform

ASPIRE develops a real-time Digital Twin (DT) platform that coordinates secure data, models, and core services across the project.

Four Domain Programs

Mobility, Manufacturing, Nursing, and Agriculture provide the field contexts in which methods are tested, compared, and refined.

Knowledge circulation

The Global Forum, the Matching Workshop, joint research, and Researcher Exchange connect Core Platform work with international collaboration.

Project structure

Five Work Packages (WPs) organize the project across management, platform work, trials, and dissemination.

  1. WP1

    Project Management for Global Knowledge Circulation

  2. WP2

    Scenarios and Use Cases

  3. WP3

    Digital Twin Platform and AI Models

  4. WP4

    Field Trials

  5. WP5

    Dissemination, Exploitation, and Standardization
